# Verona — память проекта

Статический сайт студии на Vite и обычном JavaScript, без backend и аккаунтов. Подбор выполняется локально; запись открывается в DIKIDI. Карточка вечера не создаёт бронь и не передаёт пожелания сотруднику.

Перед изменениями прочитать `.autopilot/PROGRESS.md`: там незавершённое и известные ограничения. Исходные требования и визуальное направление — `PRODUCT.md` и `VISUAL-CONCEPT.md`; не изменять их и исходную папку `intrerier/` без указания пользователя.

## Проверенные команды

- `npm ci` — установка по lockfile, проверена в чистом клоне.
- `npm run dev` — локальный сервер Vite на 127.0.0.1, обычно порт 5173.
- `npm run check` — Node tests и production build; проверены в чистом клоне и после исправления сохранений.
- `npm run build` — статический результат в `dist/`.

## Где изменять

- `src/catalog.js` — данные программ и чистый подбор.
- `src/app.js` — шаги, карточка, clipboard, PNG и локальное сохранение.
- `src/saved-answers.js` — проверка сохранённых ответов.
- `src/style.css` — оформление; `index.html` — доступное без JavaScript содержание.
- После изменения каталога выполнить `node build-html.mjs`, чтобы обновить статический каталог в HTML, затем `npm run check`.

## Ограничения данных

Прайс — снимок из PRODUCT от 07.11.2026. Полный каталог массажа, услуг для беременных и дополнений, адрес/маршрут/график, состав программ и трактовка цены для двоих требуют подтверждения. Сохранять видимые placeholders; не придумывать факты, отзывы, мастеров или настройки атмосферы. Перед публикацией сверить DIKIDI, цены, контакты и права на материалы. Реальные фотографии и локальные шрифты находятся в `public/`. Сайт пока не опубликован.
